# Codex Installer v1.1.0

## 中文

### 新功能

- 新增 Microsoft Store 高级下载安装窗口，支持 ProductId 和微软官方 Store 网页地址。
- 支持 MSIX、APPX、MSIXBundle、APPXBundle，并自动解析和安装依赖。
- 支持仅下载、下载并安装、兼容架构筛选、历史版本查看和自定义下载目录。
- 下载目录中已有完全相同且验证有效的包时直接复用。

### 安全与可靠性

- 严格验证 Microsoft Store 元数据、数字签名、Manifest、发布者、PFN、版本和架构。
- 微软 CDN 下载优先 HTTPS；仅对原始微软 HTTP 链接进行受限回退，且不会关闭证书验证。
- rg-adguard 浏览器默认隐藏，需要 Cloudflare/Turnstile 验证或等待异常时自动显示。
- 下载与安装错误现在会显示完整内部原因。
- 新增并扩展至 69 项 xUnit 测试，并由 GitHub Actions 生成构建来源证明。

### 限制

- 不支持 WPM、EXE、MSI、加密包和大型游戏安装器。
- 不绕过付费应用许可、区域限制或 DRM。

## English

### Highlights

- Adds an advanced Microsoft Store downloader for ProductIds and official Store URLs.
- Supports MSIX, APPX, MSIXBundle, and APPXBundle packages with automatic dependency resolution.
- Adds architecture filtering, download-only mode, version comparison, custom download folders, and verified local-package reuse.
- Verifies Store metadata, digital signatures, Manifests, publishers, PFNs, versions, and architectures.
- Prefers HTTPS for Microsoft CDN downloads and uses a constrained original-HTTP fallback only when required; certificate validation is never disabled.
- Shows the embedded browser only when manual Cloudflare/Turnstile verification may be needed.

This is an independent community tool and is not an official OpenAI or Microsoft installer.
