# Codex Installer v1.2.1

## 正式版 / Release

适用于 Windows x64。下载 `CodexInstaller-win-x64.exe` 后直接运行，无需预装 .NET；若缺少 WebView2 Runtime，程序会在用户确认后运行内置的微软联网引导程序。

### 新功能与修复

- 包含 v1.2 系列的本地 MSIX/APPX/Bundle 安装、本地依赖选择和打开下载目录功能。
- 界面随窗口大小自动重排，支持窄窗口纵向、宽窗口双栏和当前会话操作记录。
- 修复中文 PowerShell 输出和原始 CLIXML 弹窗，提供可复制的错误详情。
- 安装前核对签名、包身份、实际应用版本、架构、Windows 最低版本和依赖，防止自动降级。

- 新增下载线路选择：自动（直连优先）、仅 IPv4 直连、系统代理。
- 线路选择仅影响安装包传输；不修改 Clash、系统代理、系统 DNS 或证书验证设置。
- 处理 ResponseEnded、网络中断和读取超时；单次传输操作最多尝试 6 次，过期链接仍由上层重新查询一次。
- 仅在强 ETag、完整长度和续传范围一致时保留已有数据；服务器忽略 Range 或标识变化时从头下载。
- 下载完成后继续验证页面哈希（如提供）、Windows 签名、Manifest 和包族身份。
- 取消、关闭程序或最终失败会清理临时下载，不支持跨程序重启续传。

### 校验与限制

- EXE 由 `v1.2.1` 标签的 GitHub Actions 构建，并生成 GitHub artifact attestation。
- Release 附带 `SHA256SUMS.txt`。可用 `Get-FileHash .\CodexInstaller-win-x64.exe -Algorithm SHA256` 核对文件哈希。
- 使用 GitHub CLI 验证构建来源：`gh attestation verify .\CodexInstaller-win-x64.exe --repo puppnn/codex-installer`。
- 安装器本身为 x64；界面中的 arm64 是目标应用包架构选项。
- 不支持 EXE/MSI、加密包或绕过购买、许可、区域限制和 DRM。
- EXE 尚无 Authenticode 代码签名，Windows SmartScreen 可能显示未知发布者；构建来源证明不等于代码签名证书。

## English

This release adds download-route selection and validated in-session resume, and includes the v1.2 local-package installer, responsive UI, folder shortcuts, and readable deployment errors. It retains signature and identity checks without modifying Clash or Windows networking configuration.

Run `CodexInstaller-win-x64.exe` on Windows x64 without installing .NET separately. A missing WebView2 Runtime can be installed using the bundled Microsoft bootstrapper after confirmation. Verify `SHA256SUMS.txt` and the GitHub artifact attestation. Interrupted transfers resume only during the current operation; partial downloads are removed on cancellation, shutdown, or terminal failure.
