# Codex Installer v1.2.0

## 当前源码 / Not Published

- 新增打开下载目录、本地安装包预览及安装、本地依赖包选择。
- 主界面支持纵向/双栏自适应布局、固定可见的操作区，以及随高度伸缩的会话操作记录。
- 修复中文 PowerShell 输出和原始 CLIXML 错误弹窗，增加可复制的错误详情。
- 对包占用 `0x80073D02` 和 Windows 包存储库注册错误 `0x80070490` 分别提示；不会自动修改或重置系统包存储库。
- 修复重复检查沿用旧链接、验证码完成状态判断、查询和下载取消及下载超时。
- Codex 和高级模式共用依赖下载与安装前检查；禁止降级和不兼容架构安装。
- 保留 Bundle 实际应用版本，检查 Windows 最低版本，跳过可选依赖。
- 固定 WebView2 Bootstrapper 文件 URL，构建与运行时共享哈希清单，并验证微软数字签名。
- CI 分离编译、测试与发布步骤，原生命令失败立即停止。

The source adds verified local-package installation, folder shortcuts, readable deployment errors, refreshed Store queries, and shared installation preflight checks. Existing release tags and executables remain unchanged until a new release is explicitly published.
