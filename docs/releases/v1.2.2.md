# Codex Installer v1.2.2

## 源码与 CI 构建 / Source and CI Build

- 保留后台服务检测与 UAC 控制、ActivityId 部署日志、跨重启续传。
- 服务停止不再强制连带关闭依赖服务，授权后重新核对服务身份与路径。
- 部分停止失败、安装异常和取消均执行恢复检查；等待停止助手退出后才恢复，避免竞态。
- 安装成功但服务恢复失败时单独显示警告，错误详情可以复制。
- 半包移入专属缓存目录；文件锁覆盖下载、校验、移动和清理全过程。
- 仅清理有合法元数据的过期缓存，不触碰下载根目录中的其他 `.partial.*` 文件。
- 严格验证续传 JSON 的空字段、ETag、文件名和大小，坏缓存安全重下。
- 新增服务恢复和持久续传集成测试。真实 UAC、停服务与系统安装需在目标机器上人工验收。

This version retains Claude's service handling, deployment diagnostics and persistent resume features while hardening recovery, dependency boundaries, cache ownership and concurrent downloads. It is a source/CI update; existing v1.2.1 Release assets remain unchanged.
