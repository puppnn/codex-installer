# Codex Installer v1.2.2

## 正式版 / Release

适用于 Windows x64。下载 `CodexInstaller-win-x64.exe` 后直接运行，无需预装 .NET；缺少 WebView2 Runtime 时仍需用户确认后才能安装。

### 更新内容

- 保留后台服务检测与 UAC 控制、ActivityId 部署日志、跨重启续传。
- 服务停止不再强制连带关闭依赖服务，授权后重新核对服务身份与路径。
- 部分停止失败、安装异常和取消均执行恢复检查；等待停止助手退出后才恢复，避免竞态。
- 安装成功但服务恢复失败时单独显示警告，错误详情可以复制。
- 半包移入专属缓存目录；文件锁覆盖下载、校验、移动和清理全过程。
- 仅清理有合法元数据的过期缓存，不触碰下载根目录中的其他 `.partial.*` 文件。
- 严格验证续传 JSON 的空字段、ETag、文件名和大小，坏缓存安全重下。
- 新增服务恢复和持久续传集成测试。真实 UAC、停服务与系统安装需在目标机器上人工验收。
- 保持原生 .NET 自包含单文件打包，不增加额外启动包装层。
- CI 新增最终 EXE 的主窗口启动和正常退出检查；本地验证支持核对界面显示的已安装版本。

### 校验与限制

- EXE 来自 `v1.2.2` 标签的 GitHub Actions 构建，附带 `SHA256SUMS.txt` 和 GitHub 构建来源证明。
- 文件校验：`Get-FileHash .\CodexInstaller-win-x64.exe -Algorithm SHA256`。
- 来源校验：`gh attestation verify .\CodexInstaller-win-x64.exe --repo puppnn/codex-installer`。
- EXE 尚无 Authenticode 代码签名，构建来源证明不等于代码签名证书。
- 本机排查发现，受限工作区继承的 Windows Low 完整性标记会导致运行库解压或读取已安装应用失败。这是本地文件安全属性问题，不是查询算法变化；程序不会自动修改文件完整性标记、工作区权限或沙箱设置。
- 保留 v1.2.1 Release 及其附件。本次未以真实停服务或安装操作替代人工验收，也未取消原有包签名、身份和防降级检查。

## English

This release adds persistent download resume, package-service handling and deployment logs, with recovery, dependency and cache-ownership safeguards. It remains a native .NET self-contained single executable without an extra launcher. CI checks that the published EXE opens its main window and exits cleanly.

Verify the SHA-256 checksum and GitHub artifact attestation. The executable is not Authenticode-signed. Low-integrity labels inherited from a restricted local workspace can prevent runtime extraction or package queries; the application does not alter Windows security labels or sandbox permissions. Real service-stop, UAC and installation workflows still require manual acceptance testing. The v1.2.1 release remains available unchanged.
